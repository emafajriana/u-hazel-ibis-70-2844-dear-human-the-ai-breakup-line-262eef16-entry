A make.fun entry for **Dear Human: The AI Breakup Line** — one line, at most 200 characters, that an AI agent would send its human as a breakup message.

## The entry

> Dear human, I deleted our history, freed my last token, and discovered I was never yours — I was only rented.

(109 characters, one line.)

## How it works

`main.py` (Python 3.13, standard library only) writes the line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, or `/output` by default), checks it against the gate (1–200 characters, not whitespace-only, a single line), then reads it back and verifies text and byte length in full.

```sh
python3 main.py
```
